SET UP AN ENGINE

Three ways to get one

A server you already run, a model from Hugging Face, or a hosted API with a key. Each button tests before it saves, and says which check failed.

Test asks the server for its node list. For ComfyUI it also checks the MiniMax Music 3 nodes, so "saved" means it can render, not just that something answered.

Weights land in this library's models folder, and the panel names the exact folder a ComfyUI needs them in. A remote ComfyUI has to fetch them itself; this machine cannot write to it.

The key is written to its own file with 0600 permissions and never sent back to this page. Test makes one small authenticated request.

HOW IT WORKS

One list, yours.

Music Studio keeps a single playlist in REVamp called Music Studio. A take you add lands there and nowhere else, so this screen shows exactly what you added — never your audiobooks or the rest of your collection.

A take plays from this app while it is running; press Play to hear it here, or open REVamp to hear it there.
